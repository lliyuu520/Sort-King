# 《分类之王》生图要求

给生图用。运行时物品是 GLB，不是贴纸。图分成两类：

1. **UI 图**：进 Cocos 2D，叠在 3D 桌上。这是现在要生的。
2. **物品概念图**：只给建模对照，不进微信包，不贴到 3D 面上。

现有 `assets/items/*.png` 是扁贴纸（黑底、粗描边）。**不要按那套再生运行时图。** 可乐那张还是吸管杯，概念图必须改成易拉罐。

---

## 0. 先锁死

| 项 | 决定 |
|----|------|
| 玩家 | 4–8 岁，家长微信打开陪玩 |
| 画面 | 锁死俯视书桌，2.5D 塑料/黏土玩具 |
| 引擎 | Cocos 3.8，竖屏微信小游戏 |
| 设计分辨率 | 750 × 1334，出图按 2x |
| 文字 | **全部代码画**（中英切换）。图上不许有字、数字、Logo 字标 |
| 品牌 | 不许出现可口可乐 / 雪碧 / 美年达等商标。汽水做成无字通用罐 |
| 危险物 | 剪刀圆头玩具剪；动物是玩偶不是写实；交通工具是玩具车不是实车 |

不要生：完整手机截图、画框、水印、网格、多物体拼图、物品运行时精灵表。

## 1. 画风（所有图共用）

把下面整段贴进每张提示词。

**形状：** 圆角、敦实、手掌能握住。边不要锋利。

**体积：** 能看出厚度和接触面。UI 是厚塑料片；概念图是桌上小玩具。

**边：** 干净色块，允许一圈深色描边（约 4–6px @512），不要手绘速写、不要厚涂油画。

**光：** 左上 45° 柔光。高光一块、暗部一块，中间色不超过三档。接触阴影可画在物体底下，不要全场景投影。

**材质：** 幼儿园塑料 / 超轻黏土。微高光，不要金属拉丝、不要玻璃反光到能照出房间。

**背景：** 透明。不要木纹桌面、不要房间、不要假 UI 外壳。

**调色：**

| 角色 | 色 | 用在 |
|------|----|------|
| 书桌纸 | `#F3EDE3` | 只作对照，不要画进透明图 |
| 主字 | `#2B2B2B` | 代码画，不要进图 |
| 主按钮 | `#E85D4C` | 无限模式、同意、主 CTA |
| 描边 | `#C9483A` | 主按钮暗边 |
| 金 | `#E8A33D` | 星、连击、高亮 |
| 白面板 | `#FFFFFF` | 次按钮、弹层 |
| 线 | `#D9D0C3` | 次按钮描边 |
| 弱字 | `#8A8378` | 代码画 |

分类识别色（只给盒子/图标小色点，不要铺满整张 UI）：

饮料 `#5DADE2` · 零食 `#E59866` · 水果 `#58D68D` · 蔬菜 `#AF7AC5` · 文具 `#F4D03F` · 玩具 `#EC7063` · 日用品 `#48C9B0` · 动物 `#F5B041` · 交通 `#5499C7` · 服装 `#C39BD3` · 运动 `#52BE80`

**禁止：** 赛博、玻璃拟态、霓虹、写实摄影、日系厚涂、像素风、水印、英文标题、假手机壳。

## 2. 技术规格

| 类型 | 画布 | 格式 | 透明 | 内容边距 |
|------|------|------|------|----------|
| 图标 | 256×256 | PNG-24 | 要 | 主体约占 70%，四周留空 |
| 星 / 小装饰 | 128×128 或 256×256 | PNG-24 | 要 | 居中 |
| 九宫格按钮 | 512×256 | PNG-24 | 要 | 四角圆角半径 56px，内容区空，**无字** |
| 九宫格面板 | 512×512 | PNG-24 | 要 | 四角圆角半径 72px，中间空 |
| 物品概念 | 1024×1024 | PNG-24 | 要 | 单物体居中，四周约 12% 空 |
| Logo 图形 | 512×512 | PNG-24 | 要 | 无字 |

九宫格：四边留出可拉伸的直边（至少 80px 不放独特花纹），花纹只放四角。Cocos 里用 `Sprite` Type = Sliced。

文件名只用小写英文、下划线。不要中文、不要空格。

交付目录（你生完先放这里，不要直接丢进 `client/`）：

```
assets/ui/src/          # UI 原图
assets/concept/items/   # 物品概念图，文件名 = ITEMS.key
```

### C. 物品概念图（建模对照，不是贴纸）

先做英雄 3 张，过画风再铺全表。

1. `apple.png` — 红苹果，带叶，能握住
2. `banana.png` — 单根弯香蕉，不要整串
3. `cola.png` — **红色无字易拉罐**，拉环可见。禁止吸管杯、禁止 Coca-Cola 字

镜头统一：**略俯视 3/4，物体略朝右前，底面能看见。** 和游戏锁死摄像机一致（约 35°–45°）。不要正侧、不要正顶、不要人眼平视。

比例：全部按「孩子一只手能握住」来。大象、公交车做成玩具缩比，不要真实体型。苹果当尺子：其他物体在画布里的占地和苹果差不多。

## 6. 验收（你出图后自己先过）

1. 透明通道真的是空，不是黑底、不是白底。现有物品 PNG 很多是黑底，那种不合格。
2. 图上没有任何字。
3. 缩到 64×64 还能认出是什么。
4. 英雄 3 张并排：光向、描边粗细、体积感一致。
5. 九宫格图四角对称，中间没有不能拉的图案。
6. `cola` 是罐子。`sprite` / `mirinda` 无品牌。剪刀圆头。

过关后再导入 Cocos：UI 放 `client/assets/ui/`，物品概念继续留在 `assets/concept/items/`，建模出 GLB 后上传 `sortking/models/<key>.glb`。
